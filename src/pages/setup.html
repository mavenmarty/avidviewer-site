Set up a device

Enter your playlist here, get a short code, and type it on your device in Avid Viewer: Enter a setup code on the welcome screen, or Settings › Playlists › Add playlist › Use a setup code.

Private by design: your logins are encrypted in this browser with the code before anything is sent. Our server keeps only the scrambled copy, for 30 minutes, and can't read it. Avid Viewer is a media player and doesn't provide any content; add only playlists you have the rights to.

Your setup code

Type it on your device in Avid Viewer. It works until (30 minutes).

  1. Open Avid Viewer. On the welcome screen choose Enter a setup code. If you already have a playlist: Settings › Playlists › Add playlist › Use a setup code.
  2. Type the code with the remote and press Done.
  3. The device checks each playlist and adds it.
