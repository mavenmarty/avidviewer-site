Set up a TV

Enter your playlist here, get a short code, and type it on your TV in Avid Viewer: Enter a setup code on the welcome screen, or Settings › Playlists › Add playlist › Use a setup code.

A backup file from an older version of Avid Viewer (made in Settings › Updates & about). It stays locked with its PIN: the TV asks for it. Restoring needs your Avid Viewer account: you'll be asked to sign in, and the TV is linked to your account at the same time.

Private by design: your logins are encrypted in this browser with the code before anything is sent. Our server keeps only the scrambled copy, for 30 minutes, and can't read it. Avid Viewer is a media player and doesn't provide any content; add only playlists you have the rights to.

Your setup code

Type it on your TV in Avid Viewer. It works until (30 minutes).

  1. Open Avid Viewer. On the welcome screen choose Enter a setup code. If you already have a playlist: Settings › Playlists › Add playlist › Use a setup code.
  2. Type the code with the remote and press Done.
  3. The TV checks each playlist and adds it. A backup asks for its PIN.
