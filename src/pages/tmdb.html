Get a free TMDB key

Discover, genres and title details in Avid Viewer come from TMDB (The Movie Database). TMDB gives each person their own free key for personal use. It takes about five minutes.

1. Sign in to TMDB

Go to themoviedb.org and join (or sign in). Confirm your email address first: TMDB won't give a key until you have.

2. Ask for a key

  1. Open Settings › API on TMDB.
  2. Under Request an API Key, choose the link, then pick Developer. It's free for personal use. Don't pick the commercial option.
  3. Read and accept TMDB's terms of use.

3. Fill in the form

TMDB asks about the "application" the key is for. Use these, with your own name and contact details where it asks for them:

TMDB asks forEnter
Type of UsePersonal (or the closest choice, such as Other)
Application NameAvid Viewer
Application URLhttps://avidviewer.app
Application SummaryPersonal, non-commercial use. I use Avid Viewer, a TV app at home, to show movie and TV show details, posters, ratings and trending titles from TMDB on my own TVs. The key is only used on my own devices and isn't shared.
Name, email, phone, addressYour own details. TMDB uses them to contact you about your key; Avid Viewer never sees them.

Submit the form. For personal use the key usually appears straight away.

4. Copy the key

TMDB shows two values. Use the API Key: 32 letters and numbers. (The much longer API Read Access Token works too, but it's hard to type on a TV.)

5. Give it to Avid Viewer

  • Easiest, once for every TV: on this website, open Profiles, choose a profile, then Discover, and paste it under For the whole account: TMDB key. Your TVs get it within a minute while Avid Viewer is open. It's locked so the website and its admins can't read it.
  • On one TV: in Avid Viewer, open Settings › Discover, enter it under TMDB API key and choose Save. The app checks it with TMDB and says Key saved. Discover is ready.

If it doesn't work

  • "That key didn't work": check that you copied the whole API Key with no spaces, and that TMDB shows it under Settings › API.
  • No "Request an API Key" link: confirm your email address with TMDB, then sign in again.
